01 / 08 — Overview
Creative North Star
The Personal Index
A calm, durable place for the internet a person wants to keep. Not a command surface or a novelty archive — a premium product for saving videos, links, articles, repos and documents into a private Index, returning to them through an owned Feed, and choosing what contributes signal to the shared Brain.
Quiet and precise. Dark premium surfaces carry the product with very little decoration. Amber is restrained and meaningful — it marks the moments where a person saves, selects, contributes, retries, or continues.
One warm action color
Index Amber appears only on actions, active selections, focus, and current navigation — never on status or decoration.
Ownership, made legible
Private Index, owned Feed, optional contribution to the Brain — always stated in text, never color alone.
Two voices, one gradient
Inter speaks for people, JetBrains Mono for machine facts. The Brain gradient is the system's one expressive moment.
Key characteristics
—Quiet near-black plate ladder with 1px hairlines; depth is structural, not decorative.
—Status stays clear: filled tint badges in semantic hues, always paired with a text label.
—Flat by default; shadows exist only for overlays — dialogs, menus, toasts.
—Density is welcome, but every element must help someone collect, understand, return to, or share.

Do's & Don'ts
The system's guardrails
06 / 08
Do
Reserve Index Amber for actionable elements — primary buttons, active selections, focus rings, active nav, retry, invite, contribution.
Make privacy and contribution state legible — private Index, Feed, Indexed, Shared to Brain.
Render generated facts — IDs, timestamps, URLs, statuses, counts, filenames — in JetBrains Mono.
Keep badge dialects distinct — statuses filled, content types outlined, ownership labeled.
Build depth from the plate ladder plus 1px hairlines.
Use tabular-nums on counts and stats.
Keep meta text at muted (#948e84) or lighter, so it stays WCAG AA.
Provide full states for interactive components — default, hover, focus, active, disabled, loading, error.
Provide a reduced-motion fallback for every animation.
Use OwnixChevron for every wayfinding arrow — back, next, disclosure, reorder, scroll-to-top.
Shimmer the busy label whenever a user action triggers enrichment — the response always reads as acknowledged.
Don't
Make Ownix feel like a cluttered admin panel — density needs hierarchy, not everything visible at once.
Make it toy-like — no mascots, oversized emoji, bouncy motion, jokey copy, rounded-everything.
Use Index Amber decoratively, on inactive states, in status badges, or on disabled controls.
Put pending yellow on clickable controls.
Use gradient text. The Brain gradient is a backdrop, never text fill or a button treatment.
Ship hero-metric stat cards. Summary tiles are label + number, nothing more.
Use side-stripe borders as colored accents — use full borders, labeled badges, or tints instead.
Put a tracked-uppercase eyebrow above every section — uppercase mono only inside badges and table headers.
Exceed font weight 600, use display type in UI labels, or float resting cards on shadows.
Reach for a vendor arrow/chevron icon for a wayfinding control — that's what OwnixChevron is for.
Reach for a modal first. Prefer inline and progressive disclosure when it keeps the user in flow.
Full detail, states, and rules live in DESIGN.md — its frontmatter tokens are the normative source for web/tailwind.config.ts.
